The Italian Job Display Options

TIJ Options.exe sits beside TIJ.exe. Choose a resolution and click Apply or Apply & Play. Detected resolution updates after applying.

The program makes no backups. It changes only the guarded TIJ.exe resolution constants and the saved display-mode field, preserving other save data and mission fixes. Close the game before applying.

Source: GameOptions.cs. Build with the Windows .NET Framework csc compiler, referencing System.Windows.Forms.dll and System.Drawing.dll.
